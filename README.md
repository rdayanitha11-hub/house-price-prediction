# 🏠 House Price Prediction

Machine Learning project using Linear Regression to predict house prices based on features like area, bedrooms, bathrooms, etc.

## 📊 Dataset
- **File:** `Housing.csv`
- **Features:** 12 columns - area, bedrooms, bathrooms, stories, parking, etc.
- **Target:** `price`

## 🛠️ Tech Stack
- Python
- Pandas
- Scikit-learn

## 🚀 How to Run
```bash
pip install pandas scikit-learn
python house_price_prediction_ml.py
